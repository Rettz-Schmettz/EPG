# epg-builder — своя телепрограмма для плейлиста Sharavoz

Дважды в сутки GitHub собирает `epg.xml.gz` из нескольких источников и
публикует его по постоянной ссылке. В файле каналы названы **точно как в
плейлисте**, поэтому UniPlayer находит программу по названию, а сам плейлист
провайдера менять не нужно.

> Плейлист (`.m3u`) в репозиторий **не кладите**: в нём ваш токен. Здесь лежит
> только `channels.tsv` — группы и названия каналов, без ссылок.

## Установка (один раз)

1. Создайте на GitHub **публичный** репозиторий, например `epg`.
2. Загрузите в него все файлы этой папки (включая скрытую `.github/`).
3. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
4. Actions → **Build EPG** → Run workflow. Первая сборка идёт несколько минут.
5. Ссылка на файл: `https://rettz-schmettz.github.io/EPG/epg.xml.gz`,
   отчёт: `https://rettz-schmettz.github.io/EPG/report.md` (и ветка `report`).
6. В UniPlayer в контекстном меню плейлиста подключите внешний источник EPG:
   вставьте ссылку на `epg.xml.gz`.

Дальше всё обновляется само (04:17 и 16:17 по Москве).

## Что где

| Файл | Зачем |
|---|---|
| `channels.tsv` | каналы плейлиста: `группа<TAB>название` |
| `config.json` | источники по приоритету, окно дней, исключённые группы |
| `aliases.json` | ручные соответствия для каналов, которые не нашлись сами |
| `build_epg.py` | сборщик (только стандартная библиотека Python) |
| `extract_channels.py` | обновляет `channels.tsv` из нового плейлиста |

## Как это работает

- Источники перебираются сверху вниз; канал берёт программу из **первого**,
  где она нашлась. `"only"` ограничивает источник каналами по шаблону
  (свой EPG BCU — только для `BCU …`, MiniMax — для `MiniMax …` и `MS …`).
- Названия сравниваются без регистра, пунктуации и пометок качества
  (HD, FHD, 4K, HDR…), так что «Матч! Футбол 1 HD» найдёт «Матч Футбол 1».
- Каналы `(+2)`, `(+4)` … получают программу базового канала со сдвигом.
- Хранится 7 дней назад (под архив) и 8 вперёд.

## Если у канала нет программы

Откройте `report.md` → раздел «Без программы». Найдите, как канал называется
в источнике (например на epg.iptvx.one), и допишите в `aliases.json`:

```json
{
  "Матч! HD": "Матч ТВ",
  "Clarity4k Драмы": "id:clarity4k-dramy"
}
```

Для части «кинозалов» программы нет нигде — это нормально.

## Плейлист изменился

```
python extract_channels.py "Sharavoz.Tv.UniPlayer.m3u" channels.tsv
```

и закоммитьте новый `channels.tsv` — сборка запустится сама.

## Файл слишком большой / плеер грузит долго

В `config.json`: `"keep_desc": false` (без описаний передач) и/или уменьшите
`past_days` / `future_days`, либо добавьте группы в `exclude_groups`.

## Запуск у себя

```
python build_epg.py        # результат в public/
```
